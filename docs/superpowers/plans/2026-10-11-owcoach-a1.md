# OWCoach A1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lauffähige iOS-App mit Inhalten (Torbjörn, Grundlagen, Maps, Icons), Datenmodell mit iCloud-Sync, Game-Ablauf in 7 Schritten, Heute-Tab und Einstellungen.

**Architecture:** Alle Regeln (Inhalte laden und prüfen, Statistik, Vorschläge, Game-Entwurf) liegen im reinen Swift-Package `OWCoachKit` und sind dort getestet. `App/` enthält SwiftUI-Screens und SwiftData-Modelle; die Modelle werden für die Kit-Logik in Werte-Typen (`GameRecord`) übersetzt. Inhalte sind JSON-Dateien unter `Content/`, die als Ordner-Referenz in die App kopiert werden.

**Tech Stack:** Swift 6 (Kit), Swift 5 Sprachmodus (App), SwiftUI mit Liquid Glass (iOS 26), SwiftData + CloudKit, Swift Testing, XcodeGen, Python 3 (Asset-Skript).

**Spec:** `docs/superpowers/specs/2026-10-11-owcoach-design.md`

## Global Constraints

- Deployment Target iOS 26.0, nur iPhone (`TARGETED_DEVICE_FAMILY: "1"`), nur Hochformat
- Bundle-ID `de.schakal.OWCoach`, CloudKit-Container `iCloud.de.schakal.OWCoach`, Team `XU2P9PWM29`
- UI-Texte deutsch, Code-Bezeichner englisch
- Kommentare nur, wenn der Code sich nicht selbst erklärt; dann englisch, eine Zeile
- `OWCoachKit` importiert nur Foundation
- SwiftData-Modelle CloudKit-tauglich: jedes Attribut optional oder mit Default, keine `@Attribute(.unique)`, Beziehungen optional
- Touch-Ziele mindestens 52 pt hoch; Akzentfarbe Overwatch-Orange `#F99E1A`
- Kit-Tests: `swift test --package-path OWCoachKit`
- Projekt erzeugen: `xcodegen generate` (nach jeder Änderung an `project.yml` oder neuen Ordnern); `OWCoach.xcodeproj` wird mitcommittet
- Build: `xcodebuild -project OWCoach.xcodeproj -scheme OWCoach -destination 'platform=iOS Simulator,name=iPhone 17 Pro' -derivedDataPath build CODE_SIGNING_ALLOWED=NO build`
- Commits auf `main`, Push nach `origin` (git@github.com:EduardWakal/OWCoach.git) am Ende jedes Tasks

## Review Focus

1. **Erster Start, alles leer:** kein Pool, keine Wochenhelden, keine Fokus-Karte, keine Games. Heute zeigt Aufforderungen statt leerer Flächen; der Held-Schritt zeigt einen Hinweis auf die Einstellungen, wenn für die gewählte Rolle kein Held im Pool ist. Test: `GameDraftTests.heroStepWithEmptyPoolCannotAdvance` (Task 4) und Simulator-Screenshot ohne Demo-Daten (Task 11).
2. **Doppelte Einzel-Datensätze nach iCloud-Sync:** Zwei Geräte legen beide `AppSettings`/`FocusPlan` an. Die App nimmt immer den ältesten Datensatz (`createdAt`), nie einen zufälligen. Abgedeckt durch `current(in:)` in Task 8, manuell geprüft in Task 11.
3. **Spieltag-Grenze Mitternacht:** Ein Game um 23:59 und eins um 00:01 sind zwei Spieltage. Test: `StatsTests.playDaysSplitAtMidnight` (Task 3).
4. **Unbekannte IDs:** Ein gespeichertes Game verweist auf einen Helden, eine Map oder Karte, die es im Inhalt nicht mehr gibt. Anzeige mit Ersatz-Icon und der rohen ID, kein Absturz. Test: `ContentLibraryTests.unknownIDsReturnNil` (Task 2); UI-Fallback in `HeroIcon` (Task 8).
5. **Map-Suche ohne Akzente und Groß/Klein:** „paraiso“ findet „Paraíso“, „kings“ findet „King's Row“. Test: `MapSearchTests` (Task 2).

```swift
import Foundation

public struct VideoLink: Codable, Hashable, Sendable {
    public let label: String
    public let url: URL

    public init(label: String, url: URL) {
        self.label = label
        self.url = url
    }
}

public struct Card: Codable, Hashable, Sendable, Identifiable {
    public let id: String
    public let title: String
    public let question: String
    public let points: [String]
    public let rolePoints: [String: [String]]?
    public let videos: [VideoLink]

    public init(id: String, title: String, question: String, points: [String], rolePoints: [String: [String]]? = nil, videos: [VideoLink] = []) {
        self.id = id
        self.title = title
        self.question = question
        self.points = points
        self.rolePoints = rolePoints
        self.videos = videos
    }

    public func points(for role: Role?) -> [String] {
        if let role, let variant = rolePoints?[role.rawValue] { return variant }
        return points
    }
}

public struct GuideRule: Codable, Hashable, Sendable {
    public let text: String
    public let videos: [VideoLink]

    public init(text: String, videos: [VideoLink] = []) {
        self.text = text
        self.videos = videos
    }
}

public struct GuideSection: Codable, Hashable, Sendable, Identifiable {
    public let title: String
    public let rules: [GuideRule]

    public var id: String { title }

    public init(title: String, rules: [GuideRule]) {
        self.title = title
        self.rules = rules
    }
}

public struct Hero: Codable, Hashable, Sendable, Identifiable {
    public let id: String
    public let name: String
    public let role: Role
    public let guide: [GuideSection]
    public let path: [Card]

    public var iconAsset: String { "hero-\(id)" }

    public init(id: String, name: String, role: Role, guide: [GuideSection] = [], path: [Card] = []) {
        self.id = id
        self.name = name
        self.role = role
        self.guide = guide
        self.path = path
    }
}

public struct GameMap: Codable, Hashable, Sendable, Identifiable {
    public let id: String
    public let name: String
    public let mode: MapMode

    public var imageAsset: String { "map-\(id)" }

    public init(id: String, name: String, mode: MapMode) {
        self.id = id
        self.name = name
        self.mode = mode
    }
}
```

`ContentLibrary.swift`:
```swift
import Foundation

public struct ContentLibrary: Sendable {
    public let basics: [Card]
    public let heroes: [Hero]
    public let maps: [GameMap]

    public static let empty = ContentLibrary(basics: [], heroes: [], maps: [])

    public init(basics: [Card], heroes: [Hero], maps: [GameMap]) {
        self.basics = basics
        self.heroes = heroes
        self.maps = maps
    }

    public static func load(from directory: URL) throws -> ContentLibrary {
        let decoder = JSONDecoder()
        let basics = try decoder.decode([Card].self, from: Data(contentsOf: directory.appending(path: "basics.json")))
        let heroFiles = try FileManager.default
```

```swift
import Foundation

public struct PlayDay: Hashable, Sendable {
    public let day: Date
    public let games: [GameRecord]
}

public enum Stats {
    public static func recent(_ games: [GameRecord], days: Int, now: Date, calendar: Calendar = .current) -> [GameRecord] {
        guard let start = calendar.date(byAdding: .day, value: -(days - 1), to: calendar.startOfDay(for: now)) else { return [] }
        return games.filter { $0.date >= start && $0.date <= now }
    }

    public static func winRate(_ games: [GameRecord]) -> Double? {
        guard !games.isEmpty else { return nil }
        return Double(games.filter { $0.result == .win }.count) / Double(games.count)
    }

    public static func focusAverage(_ games: [GameRecord]) -> Double? {
        guard !games.isEmpty else { return nil }
        return Double(games.map(\.focus).reduce(0, +)) / Double(games.count)
    }

    public static func topDeathCause(_ games: [GameRecord]) -> DeathCause? {
        var best: (cause: DeathCause, count: Int)?
        for cause in DeathCause.allCases where cause.basicCardID != nil {
            let count = games.filter { $0.deathCause == cause }.count
            if count > 0, count > (best?.count ?? 0) { best = (cause, count) }
        }
        return best?.cause
    }

    public static func playDays(_ games: [GameRecord], calendar: Calendar = .current) -> [PlayDay] {
        Dictionary(grouping: games) { calendar.startOfDay(for: $0.date) }
            .map { PlayDay(day: $0.key, games: $0.value.sorted { $0.date < $1.date }) }
            .sorted { $0.day < $1.day }
    }
}
```

```swift
import Foundation

public struct GameDraft: Sendable {
    public enum Step: Int, CaseIterable, Sendable {
        case role, hero, map, result, focus, death, tilt
    }

    public var step: Step = .role
    public var role: Role?
    public var heroID: String?
    public var mapID: String?
    public var result: GameResult?
    public var focus: Int?
    public var deathCause: DeathCause?
    public var tilt: Int?

    public init(defaultRole: Role?) {
        role = defaultRole
    }

    public var canAdvance: Bool {
        guard step != .tilt else { return false }
        switch step {
        case .role: return role != nil
        case .hero: return heroID != nil
        case .map: return mapID != nil
        case .result: return result != nil
        case .focus: return focus != nil
        case .death: return deathCause != nil
        case .tilt: return false
        }
    }

    public var canGoBack: Bool { step != .role }

    public mutating func advance() {
        guard canAdvance, let next = Step(rawValue: step.rawValue + 1) else { return }
        step = next
    }

    public mutating func goBack() {
        guard let previous = Step(rawValue: step.rawValue - 1) else { return }
        step = previous
    }

    public mutating func choose(role newRole: Role) {
        if newRole != role { heroID = nil }
        role = newRole
        advance()
    }

    public mutating func choose(heroID id: String) {
        heroID = id
        advance()
    }

    public mutating func choose(mapID id: String) {
        mapID = id
        advance()
    }

    public mutating func choose(result newResult: GameResult) {
        result = newResult
        advance()
    }

    public mutating func choose(focus value: Int) {
        focus = value
        advance()
    }

    public mutating func choose(deathCause cause: DeathCause) {
        deathCause = cause
        advance()
    }

    public mutating func choose(tilt value: Int) {
        tilt = value
    }

    public func record(date: Date, focusCardID: String?) -> GameRecord? {
        guard let role, let heroID, let mapID, let result, let focus, let deathCause, let tilt else { return nil }
        return GameRecord(date: date, role: role, heroID: heroID, mapID: mapID, result: result, focus: focus, focusCardID: focusCardID, deathCause: deathCause, tilt: tilt)
    }
}
```

```swift
import Foundation

public enum Suggestion: Hashable, Sendable {
    case cardMastered(cardID: String)
    case switchFocus(cause: DeathCause, cardID: String)
    case moveOn(cardID: String)

    public var key: String {
        switch self {
        case .cardMastered(let id): "mastered:\(id)"
        case .switchFocus(_, let id): "switch:\(id)"
        case .moveOn(let id): "moveOn:\(id)"
        }
    }
}

public struct SuggestionInput: Sendable {
    public var games: [GameRecord]
    public var activeCardID: String?
    public var masteredCardIDs: Set<String>
    public var dismissedAtGameCount: [String: Int]

    public init(games: [GameRecord], activeCardID: String?, masteredCardIDs: Set<String>, dismissedAtGameCount: [String: Int]) {
        self.games = games
        self.activeCardID = activeCardID
        self.masteredCardIDs = masteredCardIDs
        self.dismissedAtGameCount = dismissedAtGameCount
    }
}

public enum SuggestionEngine {
    static let masteryDays = 3
    static let masteryAverage = 4.0
    static let moveOnDays = 10
    static let causeWindow = 10
    static let causeMinimumGames = 4
    static let causeShare = 0.4
    static let dismissCooldown = 3

    public static func suggestion(for input: SuggestionInput, calendar: Calendar = .current) -> Suggestion? {
        let candidates = [mastered(input, calendar), switchFocus(input), moveOn(input, calendar)].compactMap { $0 }
        return candidates.first { candidate in
            guard let dismissedAt = input.dismissedAtGameCount[candidate.key] else { return true }
            return input.games.count - dismissedAt >= dismissCooldown
        }
    }

    static func mastered(_ input: SuggestionInput, _ calendar: Calendar) -> Suggestion? {
        guard let card = input.activeCardID, !input.masteredCardIDs.contains(card) else { return nil }
        let days = Stats.playDays(input.games.filter { $0.focusCardID == card }, calendar: calendar)
        guard days.count >= masteryDays else { return nil }
        let good = days.suffix(masteryDays).allSatisfy { (Stats.focusAverage($0.games) ?? 0) >= masteryAverage }
        return good ? .cardMastered(cardID: card) : nil
    }

    static func switchFocus(_ input: SuggestionInput) -> Suggestion? {
        let window = input.games.sorted { $0.date < $1.date }.suffix(causeWindow)
        guard window.count >= causeMinimumGames else { return nil }
        var best: (cause: DeathCause, share: Double)?
        for cause in DeathCause.allCases {
            guard let cardID = cause.basicCardID, cardID != input.activeCardID, !input.masteredCardIDs.contains(cardID) else { continue }
            let share = Double(window.filter { $0.deathCause == cause }.count) / Double(window.count)
            if share >= causeShare, share > (best?.share ?? 0) { best = (cause, share) }
        }
        guard let best, let cardID = best.cause.basicCardID else { return nil }
        return .switchFocus(cause: best.cause, cardID: cardID)
    }

    static func moveOn(_ input: SuggestionInput, _ calendar: Calendar) -> Suggestion? {
        guard let card = input.activeCardID, !input.masteredCardIDs.contains(card) else { return nil }
        let days = Stats.playDays(input.games.filter { $0.focusCardID == card }, calendar: calendar)
        return days.count >= moveOnDays ? .moveOn(cardID: card) : nil
    }
}
```

```swift
import Foundation

public enum ContentValidator {
    public static func missingAssets(in library: ContentLibrary, assetCatalog: URL) -> [String] {
        let names = library.heroes.map(\.iconAsset) + library.maps.map(\.imageAsset)
        let existing = imageSetNames(under: assetCatalog)
        return names.filter { !existing.contains($0) }
    }

    static func imageSetNames(under catalog: URL) -> Set<String> {
        guard let enumerator = FileManager.default.enumerator(at: catalog, includingPropertiesForKeys: nil) else { return [] }
        var names = Set<String>()
        for case let url as URL in enumerator where url.pathExtension == "imageset" {
            let hasImage = (try? FileManager.default.contentsOfDirectory(atPath: url.path))?.contains { $0.hasSuffix(".png") || $0.hasSuffix(".jpg") } ?? false
            if hasImage { names.insert(url.deletingPathExtension().lastPathComponent) }
        }
        return names
    }
}
```

`scripts/fetch_assets.py`:
```python
#!/usr/bin/env python3
"""Download hero icons and map images, write Content/maps.json. Run from the repo root."""
import html
import json
import re
import sys
import unicodedata
import urllib.request
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
CATALOG = ROOT / "App" / "Assets.xcassets"
HEROES_URL = "https://overwatch.blizzard.com/en-us/heroes/"
MAPS_API = "https://overwatch.fandom.com/api.php?action=parse&page=Maps&prop=text&format=json"
MODES = ["Control", "Escort", "Flashpoint", "Hybrid", "Push"]
UA = {"User-Agent": "Mozilla/5.0 (OWCoach asset script)"}


def get(url: str) -> bytes:
    with urllib.request.urlopen(urllib.request.Request(url, headers=UA), timeout=30) as response:
        return response.read()


def slug(name: str) -> str:
    ascii_name = unicodedata.normalize("NFKD", name).encode("ascii", "ignore").decode()
    ascii_name = ascii_name.replace("'", "")
    return re.sub(r"[^a-z0-9]+", "-", ascii_name.lower()).strip("-")


def write_imageset(folder: Path, name: str, data: bytes, ext: str) -> None:
    group = CATALOG / folder
    group.mkdir(parents=True, exist_ok=True)
    (group / "Contents.json").write_text(json.dumps({"info": {"author": "xcode", "version": 1}}, indent=2))
    imageset = group / f"{name}.imageset"
    imageset.mkdir(exist_ok=True)
    filename = f"{name}.{ext}"
    (imageset / filename).write_bytes(data)
    contents = {"images": [{"filename": filename, "idiom": "universal"}], "info": {"author": "xcode", "version": 1}}
    (imageset / "Contents.json").write_text(json.dumps(contents, indent=2))


def fetch_heroes() -> None:
    page = get(HEROES_URL).decode("utf-8")
    urls = dict(re.findall(r'alt="([^"]+)" slot="media" src="([^"]+\.png)"', page))
    for path in sorted((ROOT / "Content" / "heroes").glob("*.json")):
        hero_id = json.loads(path.read_text())["id"]
        if hero_id not in urls:
            sys.exit(f"hero icon not found on Blizzard page: {hero_id}")
        write_imageset(Path("Heroes"), f"hero-{hero_id}", get(urls[hero_id]), "png")
        print("hero", hero_id)


def fetch_maps() -> None:
    text = json.loads(get(MAPS_API))["parse"]["text"]["*"]
    section = text[text.index('id="Standard_Play"'):text.index('id="Standard_Play_map_statistics"')]
    maps = []
    for mode in MODES:
        match = re.search(rf'id="{mode}">{mode}</span>.*?<ul class="gallery[^"]*">(.*?)</ul>', section, re.S)
        if not match:
            sys.exit(f"mode section not found: {mode}")
        for box in re.findall(r'<li class="gallerybox".*?</li>', match.group(1), re.S):
            image = re.search(r'<img alt="([^"]+)"[^>]*data-src="([^"]+)"', box)
            if not image:
                continue
            name = html.unescape(image.group(1))
            url = re.sub(r"/scale-to-width-down/\d+", "/scale-to-width-down/480", html.unescape(image.group(2)))
            map_id = slug(name)
            ext = "jpg" if ".jpg" in url.lower() else "png"
            write_imageset(Path("Maps"), f"map-{map_id}", get(url), ext)
            maps.append({"id": map_id, "name": name, "mode": mode.lower()})
            print("map", map_id)
    maps.sort(key=lambda m: (MODES.index(m["mode"].capitalize()), m["name"]))
    (ROOT / "Content" / "maps.json").write_text(json.dumps(maps, ensure_ascii=False, indent=2) + "\n")


if __name__ == "__main__":
    fetch_heroes()
    fetch_maps()
```

```swift
import OWCoachKit
import SwiftData
import SwiftUI

struct LogGameFlow: View {
    @Environment(\.content) private var content
    @Environment(\.modelContext) private var context
    @Environment(\.dismiss) private var dismiss
    let onSaved: () -> Void

    @State private var draft = GameDraft(defaultRole: nil)
    @State private var pool: [String] = []
    @State private var focusCard: Card?
    @State private var tick = 0
    @State private var prepared = false

    var body: some View {
        NavigationStack {
            VStack(spacing: 20) {
                progress
                ScrollView {
                    stepView
                        .id(draft.step)
                        .transition(.asymmetric(insertion: .move(edge: .trailing).combined(with: .opacity), removal: .opacity))
                        .padding(.horizontal, 20)
                        .padding(.top, 8)
                }
                .scrollDismissesKeyboard(.immediately)
                navigationButtons
            }
            .navigationTitle(title)
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .cancellationAction) {
                    Button("Abbrechen", role: .cancel) { dismiss() }
                }
            }
            .gesture(swipe)
            .sensoryFeedback(.selection, trigger: tick)
            .animation(.snappy(duration: 0.25), value: draft.step)
        }
        .onAppear(perform: prepare)
    }

    private var title: String {
        switch draft.step {
        case .role: "Rolle"
        case .hero: "Held"
        case .map: "Map"
        case .result: "Ergebnis"
        case .focus: "Fokus"
        case .death: "Tode"
        case .tilt: "Tilt"
        }
    }

    private var progress: some View {
        HStack(spacing: 6) {
            ForEach(GameDraft.Step.allCases, id: \.rawValue) { step in
                Capsule()
                    .fill(step.rawValue <= draft.step.rawValue ? Theme.accent : Color.secondary.opacity(0.3))
                    .frame(height: 5)
            }
        }
        .padding(.horizontal, 20)
    }

    @ViewBuilder
    private var stepView: some View {
        switch draft.step {
        case .role:
            RoleStep(selected: draft.role) { role in pick { draft.choose(role: role) } }
        case .hero:
            HeroStep(role: draft.role, pool: pool, selected: draft.heroID) { id in pick { draft.choose(heroID: id) } }
        case .map:
            MapStep(selected: draft.mapID) { id in pick { draft.choose(mapID: id) } }
        case .result:
            ResultStep(selected: draft.result) { result in pick { draft.choose(result: result) } }
        case .focus:
            FocusStep(card: focusCard, selected: draft.focus) { value in pick { draft.choose(focus: value) } }
        case .death:
            DeathStep(selected: draft.deathCause) { cause in pick { draft.choose(deathCause: cause) } }
        case .tilt:
            TiltStep(selected: draft.tilt) { value in
                tick += 1
                draft.choose(tilt: value)
                save()
            }
        }
    }

    private var navigationButtons: some View {
        HStack(spacing: 12) {
            Button {
                draft.goBack()
            } label: {
                Label("Zurück", systemImage: "chevron.left").frame(maxWidth: .infinity, minHeight: 52)
            }
            .buttonStyle(.glass)
            .disabled(!draft.canGoBack)

            Button {
                draft.advance()
            } label: {
                Label("Weiter", systemImage: "chevron.right").frame(maxWidth: .infinity, minHeight: 52)
            }
            .buttonStyle(.glassProminent)
            .disabled(!draft.canAdvance)
        }
        .padding(.horizontal, 20)
        .padding(.bottom, 8)
    }

    private var swipe: some Gesture {
        DragGesture(minimumDistance: 40).onEnded { value in
            guard abs(value.translation.width) > abs(value.translation.height) else { return }
            if value.translation.width < 0 { draft.advance() } else { draft.goBack() }
        }
    }

    private func pick(_ change: () -> Void) {
        tick += 1
        let before = draft.step
        change()
        guard draft.step != before else { return }
        let target = draft.step
        draft.step = before
        Task { @MainActor in
            try? await Task.sleep(for: .milliseconds(150))
            draft.step = target
        }
    }

    private func prepare() {
        guard !prepared else { return }
        prepared = true
        let settings = AppSettings.current(in: context)
        let focus = FocusPlan.current(in: context)
        draft = GameDraft(defaultRole: settings.defaultRole)
        pool = settings.poolHeroIDs
        focusCard = focus.activeCardID.flatMap(content.card)
    }

    private func save() {
        let focus = FocusPlan.current(in: context)
        guard let record = draft.record(date: .now, focusCardID: focus.activeCardID) else { return }
        context.insert(GameEntry(record: record))
        try? context.save()
        onSaved()
        dismiss()
    }
}
```

`pick` setzt die Auswahl sofort, damit der Knopf markiert ist, und schaltet den Schritt 150 ms später um.

```swift
import OWCoachKit
```

```swift
struct TodayView: View {
    @Environment(\.content) private var content
    @Environment(\.modelContext) private var context
    @Query(sort: \GameEntry.date) private var entries: [GameEntry]
    @Query private var progress: [CardProgress]
    @Query(sort: \AppSettings.createdAt) private var allSettings: [AppSettings]

    @State private var showLog = false
    @State private var showFocusPicker = false
    @State private var showWeekHeroes = false
    @State private var showSettings = false
    @State private var savedToast = false
    @State private var weekHeroes: [String] = []
    @State private var activeCardID: String?

    var body: some View {
        let records = entries.map(\.record)
        let mastered = Set(progress.filter { $0.masteredAt != nil }.map(\.cardID))
        let settings = allSettings.first
        let suggestion = SuggestionEngine.suggestion(for: SuggestionInput(games: records, activeCardID: activeCardID, masteredCardIDs: mastered, dismissedAtGameCount: settings?.dismissed ?? [:]))
        let todayEntries = entries.filter { Calendar.current.isDateInToday($0.date) }.reversed()

        NavigationStack {
            ScrollView {
                VStack(alignment: .leading, spacing: 16) {
                    WeekHeroesBar(heroIDs: weekHeroes) { showWeekHeroes = true }
                    if let suggestion {
                        SuggestionBanner(suggestion: suggestion, accept: { accept(suggestion) }, dismiss: { dismissSuggestion(suggestion, gameCount: records.count) })
                    }
                    FocusCardView(card: activeCardID.flatMap(content.card), role: focusRole(settings)) { showFocusPicker = true }
                    Button {
                        showLog = true
                    } label: {
                        Label("Game loggen", systemImage: "plus")
                            .font(.title3.bold())
                            .frame(maxWidth: .infinity, minHeight: 60)
                    }
                    .buttonStyle(.glassProminent)
                    StatTiles(games: records)
                    TodayGamesList(games: Array(todayEntries)) { entry in
                        context.delete(entry)
                        try? context.save()
                    }
                }
                .padding(16)
            }
            .navigationTitle("Heute")
            .toolbar {
                ToolbarItem(placement: .topBarTrailing) {
                    Button("Einstellungen", systemImage: "gearshape") { showSettings = true }
                }
            }
            .overlay(alignment: .top) {
                if savedToast {
                    Label("Gespeichert", systemImage: "checkmark.circle.fill")
                        .font(.subheadline.bold())
                        .padding(.horizontal, 16)
                        .padding(.vertical, 10)
                        .glassEffect(.regular.tint(.green.opacity(0.4)), in: .capsule)
                        .transition(.move(edge: .top).combined(with: .opacity))
                }
            }
            .sensoryFeedback(.success, trigger: savedToast) { _, new in new }
        }
        .onAppear(perform: load)
        .sheet(isPresented: $showLog) {
            LogGameFlow { showSavedToast() }
        }
        .sheet(isPresented: $showFocusPicker) {
            FocusPickerSheet(weekHeroIDs: weekHeroes, activeCardID: activeCardID, mastered: mastered) { setFocus($0) }
        }
        .sheet(isPresented: $showWeekHeroes, onDismiss: saveWeekHeroes) {
            WeekHeroesSheet(pool: settings?.poolHeroIDs ?? [], selection: $weekHeroes)
        }
        .sheet(isPresented: $showSettings) {
            ComingSoon(title: "Einstellungen")
        }
    }

    private func focusRole(_ settings: AppSettings?) -> Role? {
        if let id = activeCardID, let hero = content.heroOwning(cardID: id) { return hero.role }
        return weekHeroes.first.flatMap(content.hero)?.role ?? settings?.defaultRole
    }

    private func load() {
        _ = AppSettings.current(in: context)
        let focus = FocusPlan.current(in: context)
        weekHeroes = focus.weekHeroIDs
        activeCardID = focus.activeCardID
    }

    private func saveWeekHeroes() {
        FocusPlan.current(in: context).weekHeroIDs = weekHeroes
        try? context.save()
    }

    private func setFocus(_ cardID: String?) {
        let focus = FocusPlan.current(in: context)
        focus.activeCardID = cardID
        activeCardID = cardID
        try? context.save()
    }

    private func accept(_ suggestion: Suggestion) {
        switch suggestion {
        case .cardMastered(let id):
            context.insert(CardProgress(cardID: id, masteredAt: .now))
            setFocus(nil)
            showFocusPicker = true
        case .switchFocus(_, let id):
            setFocus(id)
        case .moveOn:
            showFocusPicker = true
        }
    }

    private func dismissSuggestion(_ suggestion: Suggestion, gameCount: Int) {
        let settings = AppSettings.current(in: context)
        var dismissed = settings.dismissed
        dismissed[suggestion.key] = gameCount
        settings.dismissed = dismissed
        try? context.save()
    }

    private func showSavedToast() {
        withAnimation { savedToast = true }
        Task { @MainActor in
            try? await Task.sleep(for: .seconds(1.5))
            withAnimation { savedToast = false }
        }
    }
}
```

```swift
            set: { on in

                if !on { pool.removeAll { $0 == id } }
            }

        mode = settings.mode
        pool = settings.poolHeroIDs

        settings.defaultRole = defaultRole
        settings.mode = mode
        settings.poolHeroIDs = pool
        let focus = FocusPlan.current(in: context)
```
